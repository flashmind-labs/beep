### Changed

- Desktop: Home's board by project shows a project only while one of its
  sessions is working or finished a turn in the last 3 hours. Projects whose
  open sessions have all been idle longer are listed below under "Earlier",
  one line each with the session count and the time of the latest one. The
  line opens the project. Inside a shown project, sessions idle longer than 3
  hours are left out, and "All N" opens the full list. The active projects on
  top of the Projects page follow the same rule.
- Desktop: Home's board is calmer when sessions are grouped by project.
  A project's box has no outline, and its rows have no lines between them.
  A harness mark has no tile. A row's second line is plain text, with no bold
  or code styling.
- Desktop: the Lanes / Projects switch sits on the same row as Home's tabs.
  It shows only while a session is open.
- Desktop: Home's machines strip no longer has "Add a machine". It stays in
  the sidebar and on the Machines tab.
- Desktop: a project's header on Home no longer shows how many sessions it
  lists. "All N" still shows when the list is cut.
