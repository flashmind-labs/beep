### Changed

- iOS: Home's board by project shows a project only while one of its sessions
  is working or finished a turn in the last 3 hours. Projects whose open
  sessions have all been idle longer are listed below under "Earlier", one
  line each with the session count and the time of the latest one. The line
  opens the project. Inside a shown project, sessions idle longer than 3 hours
  are left out, and "All N" opens the full list.
- iOS: Home's machines strip no longer ends with "Add a machine". It stays on
  the Machines tab.
